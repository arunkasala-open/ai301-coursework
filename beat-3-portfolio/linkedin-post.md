I'm excited to share my first open-source contribution to qim3d, where I worked on improving the organization of the project's test files. I found that some of the project's test files were not organized properly, so I split a large test file into two smaller files, moved four tests into two new files beside the related code, and removed an empty folder.

These tests are useful because they help developers check whether the software is still working properly after making changes. Before making the changes, I created a list of all the tests and compared it with the list after completing the work. The comparison showed that all 43 tests were still present, with exactly the same names as before. I also ran the project's test suite and confirmed that all 318 tests were passing.

It was a great learning experience to work through the issue, improve the test structure, build my own plan-check process and voice guide, and submit my changes in PR #298. Most importantly, I learned to follow the project's existing guidelines, make changes carefully, and provide evidence that my work has not affected the existing functionality. I'm looking forward to maintainer feedback and contributing more to open source.
