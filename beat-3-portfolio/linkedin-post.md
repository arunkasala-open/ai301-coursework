I'm excited to share my first open-source contribution to qim3d, a free tool scientists use to analyze 3D images and material scans. I worked on improving the organization of the project's test files and submitted my changes in PR #298.

I found that some of the project's test files were not organized properly, so I split a large test file into two smaller files, moved four tests into two new files beside the related code, and removed an empty folder. These tests are useful because they help developers check whether the software is still working properly after making changes. Before making the changes, I created a list of all the tests and compared it with the list after completing the work. The comparison showed that all 43 tests were still present, with exactly the same names as before. I also ran the project's test suite and confirmed that all 318 tests were passing.

During this project, I also created my own plan-check process, a tool that reviews my plans before I start working, and my own voice guide, a set of writing rules I created to help keep my work clear and consistent. Building and using these tools helped me learn from mistakes, improve my workflow, and become more confident contributing to open source.

I'm looking forward to maintainer feedback and future contributions!
